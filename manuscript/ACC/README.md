# Author Contributions Checklist

- `JASA_ACC_draft.docx`: editable official ACC form with the completed responses.
- `JASA_ACC_draft.pdf`: PDF copy of the form.
- `acc_form_draft.Rmd`: official R Markdown form with the same responses.
- `historical_environment.txt`: software environment recorded in a saved analysis result.

The form describes the code, data and reproduction workflow documented in the project-root `README.md`. Data provenance identifies the original studies cited in the manuscript and the Borenstein Lab repository used to download the curated data.

The templates are from the [JASA Author Contributions Checklist](https://jasa-acs.github.io/repro-guide/pages/acc.html).
